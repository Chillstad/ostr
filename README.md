# ostr (Open Source TTTRPG Resource)
A command line tool to aid running OSR style TTRPG games.

Running a true sandbox campaign can be difficult. Ostr helps you run one by making it easier to remember what went on, what was found, and what could have been found. By allowing you to reuse old tables and notes ostr helps you lead the game on the fly in situations where you don't know what comes next.
